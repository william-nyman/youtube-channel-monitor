# YouTube Channel Monitor

**This project is in active development and is not ready for use yet. More details will be added as the project progresses.**

YouTube Channel Monitor will be a self-hosted program for checking whether YouTube channels you choose to monitor have uploaded a new video and notifying you when they do.

The motivation for the project is that I do not want to keep YouTube installed and logged in on my phone. I want to avoid getting pulled in by the recommendation algorithm, YouTube Shorts, and other distractions, and instead only open YouTube when I have something specific I want to watch.
